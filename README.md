# Blank Windows App

A minimal Windows 10-compatible desktop application built with C# and Windows Forms on .NET 8. It opens a blank window.

## Requirements

- Windows 10 or later
- .NET 8 SDK

## Run

From the repository root, run:

```powershell
dotnet run --project .\BlankWindowsApp\BlankWindowsApp.csproj
```

## Build

```powershell
dotnet build .\BlankWindowsApp\BlankWindowsApp.csproj -c Release
```
